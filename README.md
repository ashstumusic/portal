# ashstu.art

Website of Ash Stu, outsider-folk singer-songwriter from Guthrie, Oklahoma.

## How it fits together

| Layer | What | Where |
|---|---|---|
| **Front-end** | Live homepage (`index.html`, built from `index-src.html` + `styles.css`) and the redesign (`redesign/index.html`, built from `redesign/index.template.html`, `redesign.css`, `redesign.js`, `effects.js`, `facts.json`) | GitHub Pages (static) |
| **Content** | One folder per release in `Audio/` (MP3s + `links.txt` with Apple/Spotify links, `date: YYYY-MM-DD`, and optionally `type: Album` / `EP` / `Single` to override the label guessed from the track count; `featured: no` keeps a release out of the featured "Latest release" spot (it still lists under Music); `order: 1` (2, 3...) sets its place in the Music list, ahead of date order; an empty `.hidden` file keeps a release off the site), videos in `Videos/`, covers in `Images/Releases/` → `releases.json`, `videos.json` via `scripts/generate_content.py` | Git; regenerated by the GitHub Action on push |
| **Lyrics** | `NN. Song.lrc` next to `NN. Song.mp3` (timestamped lines) → `lyrics.json`. Shown time-synced in the homepage's full-screen player. The album's plain text lives in `lyrics.txt` in the same folder | Git |
| **Back-end (optional)** | `server.js` (Express): contact/subscribe API, admin inbox at `/admin`, data-deletion requests | Any Node host, or your own machine. **Not** run by GitHub Pages |
| **Data** | `db.js` (SQLite via better-sqlite3): `subscribers`, `messages`, `deletion_requests`, `admin_log` | `data.db` (git-ignored; never commit it) |

The redesign shows its contact form **only** when the Node server serves the
page (the server adds `<meta name="contact-api">`). On GitHub Pages the form
stays hidden and visitors use the email address instead.

## Run everything locally

Needs Node.js 20+ and Python 3 with Pillow (`sudo apt install python3-pil ffmpeg`).

```bash
cd "Ash Music"
npm install                     # Express, SQLite driver, esbuild
npm run rebuild-native          # only if you see "libnode.so... cannot open" (Node was upgraded)
npm run build                   # regenerate releases.json/videos.json and build redesign/index.html
export ADMIN_KEY="$(openssl rand -hex 32)"   # keep this; it's the admin password
npm start                       # → http://localhost:3000  (redesign: /redesign/, admin: /admin)
```

- `npm run dev` restarts the server when `server.js` changes.
- Use a throwaway database for experiments: `DB_PATH=/tmp/test.db npm start`.
- Static preview without the back-end (exactly what GitHub Pages serves):
  `python3 -m http.server 8000`, then open http://localhost:8000/redesign/.

## Lyrics

Each song's lyrics are a standard `.lrc` file beside its MP3, one line per
lyric with its start time, for example `[01:14.25]A line of the song`.
The current *Ash Stu, Vol. II* timings were matched to the recordings
automatically; if a line highlights too early or late, change its
timestamp (any LRC editor works, or a text editor), then run
`python3 scripts/generate_content.py` to rebuild `lyrics.json` (or just push: the GitHub Action rebuilds it).

### Video captions

Each music video's captions are a WebVTT file in `Videos/Captions/` with the
same name as the video (`VCR.mp4` → `Videos/Captions/VCR.vtt`). They're picked
up automatically (`captions` in `videos.json`) and shown by default in every
video player; viewers can switch them off with the player's CC button. The
lyric text they were made from is in `Videos/Captions/lyrics.txt`. To fix a
cue that's early or late, edit its `00:01:14.250 --> 00:01:17.900` line, then
run `npm run build` and `npm run build:home`.

## Publishing

Push to `main`. GitHub Pages publishes the repository as-is (it does not run
any build), so **build before you push**:

- Changed the redesign or its content → `npm run build`
- Changed the live homepage → `npm run build:home`
- Changed Night Radio (`redesign-2/`) → `python3 scripts/build_redesign.py redesign-2`

If a Pages deploy times out ("Deployment failed, try again later"), re-run it
from the repository's Actions tab.
